NIHONGO MASTER — PWA GRATIS
============================

ISI APLIKASI
- Flashcard kotoba dengan kanji, kana/furigana, romaji, dan arti Indonesia.
- Tombol suara memakai Japanese text-to-speech dari browser/perangkat.
- Filter kategori.
- Daftar kanji dasar, hiragana, katakana, dan pola bunpou.
- Kuis pilihan ganda 10 soal.
- Progress lokal: dipelajari, dikuasai, skor kuis, dan hari belajar.
- Service worker untuk cache/offline setelah pertama kali dibuka.

CARA MENJALANKAN DI IPHONE
PWA perlu di-host pada alamat HTTPS. File yang dibuka langsung dari aplikasi Files
tidak bisa dipasang sebagai PWA.

CARA GRATIS DENGAN GITHUB PAGES
1. Buat/login akun di https://github.com
2. Buat repository baru, misalnya: nihongo-master
3. Upload SEMUA file di folder ini ke root repository.
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu GitHub menerbitkan alamat website (biasanya https://USERNAME.github.io/nihongo-master/).
8. Buka alamat itu lewat Safari iPhone.
9. Tekan tombol Share/Bagikan (kotak dengan panah ke atas).
10. Pilih Add to Home Screen / Tambahkan ke Layar Utama, lalu Add.

CATATAN PENTING
- Hosting GitHub Pages gratis untuk repository publik.
- Domain github.io gratis; domain .com tidak termasuk.
- Progress disimpan di browser/perangkat yang digunakan, bukan akun cloud.
  Jangan hapus data website/Safari jika ingin menjaga progress.
- Suara menggunakan fitur speechSynthesis perangkat. Ketersediaan suara Jepang
  bergantung pada iOS/browser dan bahasa suara yang tersedia.
- Font Google dapat memerlukan internet; fitur inti tetap bekerja setelah cache.
- Materi saat ini adalah starter N5, bukan silabus N5/N4/N3 lengkap.
- Data tersimpan lokal dan belum tersinkron antarperangkat.
